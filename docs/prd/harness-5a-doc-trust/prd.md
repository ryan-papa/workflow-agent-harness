# PRD: 5a 문서 근거 진실 추정 전환

**상태:** In Review
**유형:** 하네스 메타 변경 (간소 PRD)

---

## 변경 이유

1. **1차 완화의 억제 장치가 완화를 무효화** — [`20261001_5a-doc-evidence.md`](../../research/20261001_5a-doc-evidence.md) 는 문서 서술을 I·A 근거로 허용하면서 기준선 요건(같은 PR 서술 불인정) · 모순 검사 의무 · 서술 PR 의 N/A 금지 · 미검증 영속 표기를 동시에 부과했다. 결과적으로 내부 전용 서술이 있는 API 도 **"문서를 신뢰할 수 없다" 는 일반 논거로 E 재판정**되는 사례가 반복됐다 (관측 → [`5a-observations.md`](../../research/5a-observations.md) 2026-10-15 행). 1차 완화와 달리 **관측 근거가 있는 완화**다.
2. **I 구조적 상한 7 이 평균 축을 잠식** — 보안 항목에는 감점형 규칙이 걸리지 않으므로(감점형은 1·2·7 전용) 상한 7 은 최저 축(≥7)을 막지는 않는다. 문제는 **평균 축(≥8.0)** 이다 — 내부 API 는 구조적으로 보안이 7 로 고정되어 나머지 6항목이 평균 8.0 을 메워야 하고, 정상 설계도 다른 항목 1~2점 감점으로 평균 미달에 걸린다. 상한 8 은 이 잠식을 해소한다(7항목 평균 +0.14).
3. **불인정 사유가 열거되지 않아 리뷰어 재량이 무제한** — 1차 규칙은 요건을 "전부 충족" 으로 나열했을 뿐, **무엇이 불인정 사유인지**를 닫힌 목록으로 고정하지 않았다. 리뷰어마다 같은 PR 에서 E/I 가 갈리는 비결정성이 남았다.

### 잔존 위험 (사용자 인지·수용)

결정 5 는 1차 완화 리뷰에서 기획·엔지 양축이 독립적으로 최대 결함으로 지적한 **자가 선언 경로**를 재개방한다 — 같은 PR 에 "내부 전용" 1행을 추가해 E(상한 3, 미달) → I(상한 8, 통과)로 전환할 수 있다. **최대 폭**: 1차의 `라우트 무변경` 요건(라우트 = 핸들러 매핑 + 게이트웨이·ingress 등록)도 함께 철회되므로, **이 PR 에서 라우트와 서술을 동시에 신설한 신규 엔드포인트**도 문서 1행으로 I 확정이 가능하다 (선행 예고 사유는 동시 추가 시 성립하지 않는다). 결정 4 는 불일치가 리뷰 단계에서 적발되지 않을 여지를 남긴다. 사용자가 이 비용을 인지한 상태에서 "문서에 서술된 것은 신뢰한다" 를 기본값으로 선택했으며, 근거·한계는 research 기록에 등재했다.

**잔존 가드**: 선행(예고) 서술 불인정 · 상충·삭제 · 대상 불명 · **계획 서술**(미래 시제) · 요소 결손 · 모순을 실제로 발견한 경우의 E · 원장 4카운터(`5a 오탐`·`문서 근거 오판`·`반증불가`·`문서 근거 과엄격`).

### 범위 환원 (리뷰 반영)

초안에서 "레포 밖 문서(사내 위키·문서 전용 레포)도 PR 본문 인용 발췌 시 인정" 을 넣었으나 **철회**했다 — 사용자 결정 목록에 없고, 1차 PRD 가 리뷰 지적으로 명시 철회한 조항이며(레포 밖 문서는 구성상 항상 diff 밖 + 반증 수단 0), §2 정의문과도 충돌했다. 완화 범위는 **리뷰 대상 레포의 프로젝트 문서**로 한정한다.

### 유지한 제약

`역할검사`(A 등급 역할·스코프 검사 코드)·`호출측검증`(판정행 2·4b 해제 조건)은 **문서로 충족 불가**를 유지한다. 두 요소는 노출 면 서술이 아니라 **검사 코드의 실재 자체가 판정 근거**이므로, 문서로 열면 "검증한다고 쓰여 있으나 코드에 없는" 상태가 해제 사유가 된다.
