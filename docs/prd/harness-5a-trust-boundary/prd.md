# PRD: 5a 파라미터 위변조 방지 — 노출 등급(E/I/A) 선행 판정

**상태:** In Review
**유형:** 하네스 메타 변경 (간소 PRD)

---

## 변경 이유

1. **과잉 차단 해소** — PR #67·#68 로 도입한 코드리뷰 5a 는 신뢰 경계를 "클라이언트 = 불신" 으로 고정했다. mTLS·서비스 메시 사이드카로 전송 계층에서 호출자 인가가 확립된 내부 API 도 보안 최대 3점 상한에 걸려, 주체 결정을 호출측 서비스가 맡는 정상 설계가 미통과 처리된다. 기존 N/A 경로는 "인증 불요 공개 리소스" 만 덮어 이 케이스에 적용 불가 — 내부 API 는 인증이 없는 게 아니라 **인증이 다른 계층에 있다**.
2. **판정 합성 규칙 부재** — PR #68 의 FAIL형 → 상한형 전환 과정에서 동일 항목 복수 상한 적중·상한 × 감점 중첩의 처리 규칙이 정의되지 않아, 구 규칙에서는 불가능했던 통과 역전 경로가 생겼다 (1a 7 + 1b 6 동시 적중 시 최대값 채택하면 통과).
3. **문서 분량 규칙 현실화** — 기본 300줄 / 최대 500줄 2단 기준이 실제 운영에서 경고만 누적시켰다. 500줄 단일 기준으로 통일한다.

### 분량 기준 변경을 동일 PR 에 포함한 근거

500줄 단일 기준은 5a 와 직교한 별개 결정이며 사용자 지시로 확정됐다. 본 PR 이 `harness-code-review.md` 를 키운 것과 인과 관계가 없다 — 기준 변경 없이도 해당 파일은 hard limit 500 이내였고, 변경된 것은 **경고 임계(300)** 뿐이다. 분리 PR 로 뺄 경우 같은 파일을 두 PR 이 건드려 충돌 비용만 발생한다.

## 롤백 전략

문서 전용 변경이며 런타임 영향 없음. `git revert` 로 단일 커밋 되돌리기 가능하다.

부분 롤백 축:

| 축 | 되돌릴 때 영향 |
|----|----------------|
| 노출 등급 도입 | 5a 가 PR #68 상태(전면 적용)로 복귀 — 내부 API 과잉 차단 재발 |
| 합성 규칙 | 복수 상한·감점 중첩이 다시 미정의 상태로 복귀 (통과 역전 경로 재개방) |
| 500줄 단일 기준 | CI 경고 재발생, 실패 임계는 불변(500) |

등급 완화가 과하다고 판단되면 전체 revert 대신 **I 등급 해제 매트릭스만 축소**(안티패턴 2·3 를 적용으로 환원)하는 경로를 우선한다.
