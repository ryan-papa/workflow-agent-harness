## E 확정 조건 (결정 1)

다음 중 하나가 레포에서 **실제로 확인**될 때만 E. 확인되지 않으면 I.

| 근거 | 예 |
|------|----|
| 공개 라우트 등록 | 퍼블릭 게이트웨이·ingress·공개 라우터에 해당 경로 등록 |
| 인증 예외·공개 설정 | `permitAll`·공개 어노테이션 등 |
| 문서 서술 | README·docs 에 대고객·퍼블릭 API 로 **현재 시제** 서술 (예정형 제외) |
| 클라이언트 호출 | 같은 레포의 대고객 앱·웹 코드가 해당 엔드포인트 직접 호출 |

**A 확정 조건**: 운영자 인증 설정 또는 역할·스코프 검사 코드가 해당 엔드포인트에 확인되거나, 문서가 운영자 전용으로 현재 시제 서술. E 확정 조건과 동시 충족 시 E + A 중첩(§1 중간 형태 유지).
