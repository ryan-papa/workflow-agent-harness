**상태:** Approved ([4] 8.0 · [5] 8.2 · [9-코드] 8.7)
**유형:** 하네스 메타 변경 (간소 PRD)

---

## 변경 이유

| # | 문제 | 근거 |
|:-:|------|------|
| 1 *(핵심)* | 개발 가이드(`harness-dev.md`)는 절차만 다루고, 소소한 중복의 추출·책임 몰아넣기 지양 기준이 없음 | 메인 확인 (2026-10-28) |
| 2 | Simplicity "요청 없는 추상화" 금지(-1)가 변경 범위 내 중복 추출까지 억제할 여지 | 사용자 지적 |

## 결정 사항 (사용자 확정)

| # | 항목 | 결정 | 기각 대안 | 근거 유형 |
|:-:|------|------|-----------|-----------|
| 1 | 성격 | **참고 가이드** — 감점·차단 없음 | 리뷰 코멘트 의무화 | 사용자 결정 |
| 2 | 위치 | `harness-dev.md` "코드 작성 참고" 절 (리뷰 문서 무변경) | 리뷰 문서 · CLAUDE.md 표 행 추가 | 사용자 결정 |
| 3 | Simplicity 충돌 | CLAUDE.md Simplicity 반례에 "변경 범위 내 반복 로직의 추출은 제외" 단서 | 방치 · Simplicity 완화 | 사용자 결정 |

## 경계 기준

| 구분 | 기준 |
|------|------|
| 추출 고려 | 이번 변경 범위에서 같은 로직 **2회 이상** 반복 (예: 신규 핸들러 2곳의 동일 검증 로직) |
| Surgical 적용 | 이번 변경이 건드리지 않는 기존 코드의 중복 (예: 무관 모듈의 기존 유틸 통합) |

## 영향 파일

|------|------|
| `docs/harness-dev.md` | "코드 작성 참고 (중복·구조)" 절 신설 |

로컬 CI 3종(필수 파일·500줄·내부 링크) 통과 · `sync-codex-skills.py --check` 통과.
