# PRD: 5a 등급 증거 완화 — 프로젝트 문서 서술 인정

**상태:** In Review
**유형:** 하네스 메타 변경 (간소 PRD)

---

## 변경 이유

1. **증거 조달 비용 과다** — 현행 [`harness-trust-boundary.md`](../../harness-trust-boundary.md) §2 는 I·A 등급 증거를 **설정·코드 원문**으로만 인정한다. 메시 정책·게이트웨이 허용목록은 통상 리뷰 대상 레포 밖에 있어 PR 본문 원문 발췌가 강제되고, 발췌 시 민감 정보 일반화 의무까지 중첩된다. 결과적으로 내부 전용임이 분명한 API 도 조달 비용 때문에 fail-closed → E 재판정으로 떨어진다.
2. **문서를 1회 도입하면 재사용 가능한 경로가 없음** — 현행 규칙에서는 README 에 노출 면을 적어 두어도 증거가 되지 않아, 리뷰마다 설정 원문을 다시 조달한다. 실측(서브레포 `README.md` 31개 전수 grep — `내부 전용|노출 면|허용 호출자|사내 전용|internal-only`)에서 해당 서술은 사실상 부재이므로 **"이미 있는 서술을 즉시 쓴다" 는 효용은 현 모집단에서 거의 0** 이다. 실제 가치 경로는 **기준선 서술을 1회 도입(진입점: README 규칙·템플릿) → 이후 PR 에서 재사용** 이다.
3. **선제적 완화임을 명시** — 1·2 는 구조적 논증이며 **관측 사례 ID 는 없다**. §5 의 "기록 없이 완화 금지" 를 충족하기 위해 회차·사유·한계를 [`research/20261001_5a-doc-evidence.md`](../../research/20261001_5a-doc-evidence.md) 에 등재했다. 선례 없는 완화이므로 철회 트리거(`문서 근거 오판` 2건)가 유일한 안전망이다.

### 완화에서 제외한 요소 (설계 판단)

`호출측검증` 증거는 **코드 원문 발췌 요구를 유지**한다. 이 요소는 노출 등급 증거가 아니라 **판정행 2·4b 해제 조건**이며, 소유권 검증 코드의 실재가 곧 판정 근거다. 문서 서술로 대체하면 "검증한다고 쓰여 있으나 코드에 없는" 상태가 해제 사유가 된다. `역할검사`(A 등급)도 동일 이유로 파일·줄 요구 유지.

### 잔존 보안 비용 (사용자 인지·강행 결정)

E→I 전환이 성립하면 판정행 1·3·5·6 이 해제되므로, 문서 근거 경로는 **보안 상한 3(미달) → 7(통과)** 전환을 만든다. 결정 2 의 -1 하향은 이 전환을 억제하지 못한다. 억제 장치는 결정 5(기준선 문서) + 인용 의무 + 사후 관측 3종이며, **잔존 비용은 사용자가 인지한 상태에서 수용했다**. 근거·한계는 research 기록에 등재.
