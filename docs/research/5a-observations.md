# 5a 관측 원장

[`../harness-trust-boundary.md`](../harness-trust-boundary.md) §5 재검토 트리거의 **누적 카운터 영속 매체**. 본 원장은 카운터 **정의를 단독 보유**하며, 각 카운터의 임계·기록 경로는 SSOT §5 표를 따른다. 리뷰 본문은 인-메모리라 보존되지 않으므로 **append 주체는 항상 메인**이다 (서브에이전트는 파일 생성 금지). 회고[12]는 실행 시 본 원장을 집계한다.

| 카운터 | 임계 | 정의 |
|--------|:----:|------|
| `5a 오탐` | 3건 | 판정표 적중으로 상한이 걸렸으나 실제 위변조 위험이 없던 건 |
| `문서 근거 오판` | 2건 | 문서 서술과 실제 노출·인가 설정의 불일치가 **서술 머지 이후 어느 시점에든 확인된 건**(§2 모순 검사 적중 포함) |
| `반증불가` | 임계 없음 | `격리` 가 레포 밖 설정으로만 성립해 모순 검사로 반증할 수 없는 문서 근거 건 — 모집단 관측용(판정은 그대로 진행) |
